# Marstek brand assets

`icon.png` (256 × 256) and `icon@2x.png` (512 × 512) are copied unchanged from the [Marstek assets in Home Assistant's brands repository](https://github.com/home-assistant/brands/tree/df126d0dd608f5ba31208d35c5f5a08d0d426e4d/custom_integrations/marstek).

The Marstek name and logo belong to Marstek. The assets identify the supported hardware; the project's software licenses do not grant trademark rights.

Run `scripts/sync.py` to copy both images into `custom_components/marstek/brand/` and update the package checksums. Home Assistant uses these local brand images in its integration menus, including the higher-resolution variant where requested.
